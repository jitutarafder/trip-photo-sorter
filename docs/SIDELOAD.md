# Sideloading Trip Photo Sorter on iOS (Windows + Free Apple ID)

This guide explains how to install the unsigned `.ipa` generated by GitHub Actions onto your iPhone from a Windows PC at **$0 cost** using Sideloadly.

---

## 1. Prerequisites (One-time setup on Windows)

1. **Standalone iTunes for Windows (Non-Microsoft Store)**:
   - Sideloadly requires Apple's native mobile device libraries.
   - If you have iTunes from the Microsoft Store, uninstall it.
   - Download and install the direct Windows installer from Apple:
     - [iTunes 64-bit for Windows](https://www.apple.com/itunes/download/win64)
2. **Standalone iCloud for Windows (Non-Microsoft Store)**:
   - Download the standalone version directly from Apple:
     - [iCloud for Windows (direct download)](https://updates.cdn-apple.com/2020/windows/001-39935-20200911-1A70AA56-F448-11EA-8109-814837D35F02/iCloudSetup.exe)
3. **Install Sideloadly**:
   - Download and install Sideloadly from [sideloadly.io](https://sideloadly.io/).
4. **Apple ID**:
   - A standard free Apple ID (no paid developer account needed).
   - *Recommendation:* You can use a secondary/burner Apple ID for peace of mind.

---

## 2. Download the Unsigned `.ipa` Artifact

1. Push your code to your public GitHub repository.
2. In your browser, navigate to your repository on GitHub.
3. Click the **Actions** tab.
4. Select the **iOS Unsigned Build** workflow run.
5. Under **Artifacts** at the bottom of the page, download `TripPhotoSorter-unsigned-ipa.zip`.
6. Extract the zip file on your Windows PC to obtain `TripPhotoSorter-unsigned.ipa`.

---

## 3. Install the App using Sideloadly

1. Connect your iPhone to your Windows PC with a USB cable.
2. Unlock your iPhone. If prompted with **"Trust This Computer?"**, tap **Trust** and enter your passcode.
3. Open **Sideloadly** on your Windows PC:
   - In the **Device** dropdown, ensure your connected iPhone is selected.
   - In the **Apple ID** field, enter your Apple ID email address.
   - Drag and drop `TripPhotoSorter-unsigned.ipa` onto the large IPA icon on the left.
4. Click **Start**.
5. When prompted, enter your Apple ID password and the 2-Factor Authentication (2FA) verification code displayed on your iPhone.
6. Wait for Sideloadly to sign and install the app until the status bar says **"Done"**.

---

## 4. Enable Developer Mode & Trust Certificate (First Time Only)

Before iOS will allow the sideloaded app to run:

### Step 4.1: Enable iOS Developer Mode (iOS 16+)
1. On your iPhone, open **Settings** → **Privacy & Security**.
2. Scroll to the bottom and tap **Developer Mode**.
3. Toggle Developer Mode **ON**.
4. Tap **Restart** when prompted.
5. After the iPhone reboots and unlocks, tap **Turn On** on the alert and enter your passcode.

### Step 4.2: Trust Developer Certificate
1. On your iPhone, go to **Settings** → **General** → **VPN & Device Management**.
2. Under **Developer App**, tap your Apple ID email.
3. Tap **Trust "[Your Apple ID]"**, then confirm by tapping **Trust**.

---

## 5. Connecting to Metro Server for Development

Because the app is built with `expo-dev-client`:
1. Ensure your iPhone and Windows PC are connected to the **same Wi-Fi network**.
2. On your Windows PC in the project root, start the Metro dev server:
   ```bash
   npx expo start --dev-client
   ```
3. Open the **Trip Photo Sorter** app on your iPhone.
4. The dev client launcher screen will open:
   - You should see your PC's Metro development server listed under "Development servers". Tap it to load the JavaScript bundle.
   - Or select **"Enter URL manually"** and input `http://<PC-LOCAL-IP>:8081` (find your PC IP via `ipconfig`).
5. **Fast Refresh is active:** All TypeScript/JavaScript changes in `src/` or `app/` update instantly on your iPhone over Wi-Fi without needing a new build.

---

## 6. Free Apple ID Limits & Weekly Re-signing

- **7-day expiration:** Apps signed with a free Apple ID expire after 7 days.
  - To re-sign, simply reconnect to Sideloadly and install the IPA again (or leave Sideloadly running with automatic Wi-Fi refresh enabled).
- **Max 3 apps:** Free Apple IDs can only have up to 3 sideloaded apps active simultaneously on a single device.
- **10 App IDs per 7 days:** Apple limits free accounts to 10 unique App IDs per rolling 7-day period.

---

## 7. When is a New GitHub Actions Build Needed?

- **JS/React changes:** NO new build needed. Just edit code on PC and Metro reloads on your iPhone.
- **Native changes:** A new GitHub Actions build is ONLY required when:
  - Adding or removing native npm packages (`react-native-*`, native Expo modules).
  - Modifying `app.json` plugins, permissions, or native configurations.
  - Updating Expo SDK version.
